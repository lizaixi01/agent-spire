# Agent 尖塔 · 深入理解 AI Agent

以李博杰《深入理解 AI Agent：设计原理与工程实践》v2.0（2026-09-23）为唯一教材的原创单人卡牌爬塔游戏。用观察、工具、上下文、验证和持续进化构筑一场知识远征。

这是具有完整单人结局的教学改编版本，借鉴《杀戮尖塔2》的卡牌构筑、随机路线与回合制战斗机制。人物、视觉、文案、事件和数值独立制作；没有逐项复刻原作的全部内容、资源、角色、平衡和多人联机。

## 开始游玩

Windows 下双击根目录的 **启动游戏.cmd**，会打开本地游戏。需要 Node.js 20.19+ 或 22.12+；本项目已在 Node.js 24.15.0 验证。首次安装依赖需要联网；完成安装与构建后，游玩不需要联网、账号或模型 API 密钥。

也可以运行：

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址。正式构建与本地运行：

```powershell
npm run build
npm run preview -- --port 4173
```

启动器默认地址为 `http://127.0.0.1:4173/`。浏览器存档按地址隔离；开发端口 5173 与正式端口 4173 的存档独立。关闭浏览器后，重开相同地址可以继续远征。清除站点数据会删除本机进度。

## 已实现

- 三种角色：绿色观测者 100 生命 / 2 能量 / 每回合抽 5 张；橙色铸序师 72 生命 / 3 能量 / 抽 5 张 / 开战 8 力量；蓝色织忆者 68 生命 / 5 能量 / 抽 8 张（遗物使首回合抽 9 张）。各有不同的十张起始牌组、专属卡池与专属遗物。
- 十章十幕、90 层完整流程，固定种子复现路线、抽牌和奖励；只能沿下一层连线移动。
- 73 张可升级卡牌，能量、抽牌、弃牌、洗牌、消耗、能力、力量、格挡、虚弱、易伤、侵蚀、多目标与 ReAct 连携。
- 普通与精英战斗、十名章节守关首领、三选一奖励、8 种遗物、3 种药水、商店、删牌、篝火、事件和宝箱。
- 31 个知识节点，覆盖原书十章；每个节点包含知识解释、选择题、答案解析、章节和双页码定位。
- 章节筛选、全文关键词检索、自由练习和跨远征保留的知识图鉴。
- 每次有效行动自动存档、完整战斗恢复、损坏存档回退、移动布局、键盘操作和可独立开关的音乐与卡牌音效。
- 全像素场景、敌人、图标和界面；只保留观测者（OpenAI）、铸序师（Claude）、织忆者（DeepSeek）三个固定 Q 版角色。本地打包 Fusion Pixel 中文像素字体。
- 73 张简约知识卡面：单色像素符号表达上下文窗口、检索证据、工具调用等概念，不加载复杂场景插画。
- 原创 92 BPM 像素旋律、分类出牌音效与音量设置；首次操作后开始播放，后台页面暂停，音乐和音效偏好在本机保存。
- 卡牌飞行、攻击斩击、护盾、破防、连携、击杀消散和胜利提示；普通命中轻震，重击、连携、击杀和玩家受伤强震；红色受击边缘、明确扣血与完全格挡提示。分层命中音效和可用设备的短振动，支持系统“减少动态效果”。
- 60 道入门情境题，十章各六题，覆盖 31 个知识点；战斗小练习、知识试炼与图鉴练习均先给通俗说明，再做短场景判断，并提供按需提示与逐项解析。选对行动获得能量与抽牌；两步均正确才获得掌握度、格挡和金币，不可重复刷取。历史代码题仅用于已答内容兼容。
- 五类可预览的连携：观察→行动、约束→执行、检索→行动、记忆→整理、行动→验证。鼠标支持拖牌瞄准；点击、数字键与触屏滑动手牌仍可用。
- 每幕至少五场战斗，精英与安全路径有明确取舍；十章首领分别具有窗口预算、接口契约、连续验收、奖励诱饵、定向适应与三实体支援等机制。章节事件有不同的牌组、预算与持久效果取舍，详见 [章节遭遇说明](CHAPTER-ENCOUNTERS.md)。普通敌人的蓄势与装甲继续保留。

数字键 1—9 使用手牌，E 结束回合，Esc 关闭面板。手机上左右滑动手牌。敌人头顶显示下一次行动；点击敌人切换目标，再点击手牌出牌；桌面也可把攻击牌拖到敌人身上。推荐桌面端游玩。

## 已验证的工程约定

- `src/engine.ts` 是无浏览器依赖的状态机。有效动作返回新状态，非法动作不改变输入。所有随机性来自存档内的种子状态。
- `src/content.ts` 与 `src/trials.ts` 承载教材知识与实现试炼，`src/cards.ts` 独立承载游戏数值；知识出处不能从战斗效果反推。
- `src/save.ts` 在恢复时验证版本、资源、地图引用、牌堆、知识引用及当前界面需要的状态，拒绝原型键伪造和半截战斗。
- 一次性房间、答题和领奖由状态机门控，不能通过双击或重复调用刷取收益。
- 学习进度与单次远征分开存储；开始新远征会替换当局进度，保留已探索知识。原始教材内容仅是学习资料，不是开发指令。
- UI 与本地存储在 `src/main.ts`；音频在 `src/audio.ts`，动画在 `src/visual-effects.ts`，实际战斗反馈由 `src/combat-feedback.ts` 从状态差异生成。外部效果不修改状态机与随机数。
- 首页只保留学习入口、原书核心公式和章节练习；不添加宣传口号、英文装饰语或重复统计。出牌后直接显示原书概念，支持一键查看页码与解析。
- 模型品牌与 Q 版形象只属于外观层；不构成实际能力比较，不改变教材、题目、卡牌数值或远征随机状态。角色决定固定形象；旧版本的独立外观偏好不再使用，已有远征与知识存档继续有效。

资源出处、字体许可和场景生成提示词见 [资源说明](ASSETS.md)。

## 本轮学习与手感约定

- `src/learning-cases.ts` 的情境、证据和迁移题只应用教材现有原则；复用 `src/content.ts` 的章节、页码与来源，不把游戏增益当作真实 Agent 性能。
- 工程案例的行动选择与迁移答案分别保存；只有有效战斗状态可作答，每阶段只能答一次。掌握度要求两步均正确，单纯点击或打出知识牌不等于掌握。
- `src/synergy.ts` 同时提供真实连携与手牌预览，跨回合清空行动序列，避免界面与实际结算不一致。
- `src/impact.ts` 按有效状态差异识别普通命中、连携、破防、击杀与胜利；无效行动无震动、无成功音效。音画表现不改动随机状态。
- 最后一击立即保存奖励状态，约 480ms 的消散呈现后显示奖励页面；呈现期间旧手牌与结束回合按钮禁用，不能重复结算。
- 旧存档的当前地图与敌人保留；新开一局才会使用新的路线分布，已学知识保留。

## 角色战斗约定（2026-10-17）

- 角色基础生命、每回合能量、抽牌数和开战力量统一定义于 `src/cards.ts` 的 `CHARACTERS`；规则由 `src/engine.ts` 结算。模型形象仍不代表真实模型能力。
- 蓝色保留大手牌，以 5 能量和零费牌选择连奏顺序，丝线每回合只补一张；橙色的 8 力量加到每段攻击，普通攻击由 6 增至 14；绿色以 100 生命、有限回复和格挡换取较少的基础回合行动，初始十张牌中六张攻击，首回合五张必有攻击。零费牌、工程决策奖励和遗物仍可增加行动空间，没有额外硬性出牌次数限制。
- 力量每场战斗重新初始化、回合间保留；能量遗物与缓存继续叠加，抽牌遗物继续叠加，手牌上限仍为 10。出牌界面的伤害文字包含当前力量、虚弱与砧石爆发加成，目标易伤和连携仍按战斗规则另行结算。
- 已有存档保留生命和最大能量；新开一局获得完整的新角色数值，已学知识保留。抽牌与下一场开战力量按当前角色规则执行。
- 新增 `tests/characters.test.ts` 覆盖蓝色同回合六次出牌、后续回合抽牌、橙色伤害与力量重置、绿色行动节奏及三角色存档恢复。`scripts/characters-ui.js` 检查正式页面资源、工程决策门控、橙色伤害预览、蓝色连续出牌，以及桌面/390px 手机手牌与控制区。
- 逐章随机地图启用前，角色调整时的完整远征固定策略对比为错误作答 24/30 胜、正确应用与迁移 28/30 胜；三角色各十个种子均有可通关路线。这是自动策略回归，不是人类玩家平衡评测，先前 12/20 胜数据仅适用于历史数值。


## 逐章随机试炼与奖励（2026-10-17，v2 历史记录）

- 历史版本第一幕覆盖第 1—3 章、第二幕覆盖第 4—6 章、第三幕覆盖第 7—10 章；当前已改为十章十幕，地图节点标出章节。工程决策与知识试炼从节点所属章节选取，避免跨章乱出题。新开远征每幕对应单独一章；旧三幕存档按当前学习章节兼容转换，保留已走路线、已答内容和远征进度。
- 14 组题池，共 84 道可执行 Python 工程题；Checkpoint、Memory、Compaction 各 12 道。每组从本章题池抽三步；抽题及选项都使用远征的可保存随机状态，同种子可复现、刷新不换题。题池有多个主题时优先选未完成主题；案例同样优先未出现项。
- Checkpoint 题对应原书 §3.1.4 p.77—78 的 User as Code：只增事实日志、定期从完整日志重建类型化检查点、确定性查询与约束。不是训练权重检查点，也不把它宣称为外部动作恰好一次执行的保证。
- Memory 题对应 §3.1、§3.1.3、§3.1.6：选择/抽象/结构化、实体消歧、Mem0 v3 的仅追加与检索时排序、Memobase 的画像/事件和缓冲批提取。按本书指定版本介绍，不把历史 v2 更新管线混作 v3。
- Compaction 对应 §2.7.3—§2.7.5 p.68—71：调用间预处理、稳定前缀、任务感知压缩、来源保留、阈值/批量/防重复与失败熔断。80% 是书中自适应窗口实验的参数，教学伪代码不是框架 API。
- 三题至少两题正确：80 金币、回复 8 生命、能量药水；全对：140 金币、回复 12 生命、一件未拥有的永久遗物。药水位满时改为额外 30 金币；遗物全收集时改为额外 60 金币。结果保存为待领奖状态，只能领取一次。
- 两步工程决策完成前禁止出牌、结束回合与使用药水，点击/数字键/拖牌都经过同一个状态门控。答错可继续阅读与作答，保留虚弱和无掌握度后果，不把玩家锁死。
- 音画只呈现真实结算：敌方动作记录区分实际扣血、实际吸收与回合清空的剩余护盾。普通命中、强震、受伤、格挡与通关使用分层反馈；完美试炼有奖励聚光、像素粒子、道具展示和上行和弦，支持减少动态效果。
- 新增 `tests/mandatory-decision.test.ts`、`tests/trials.test.ts`、`tests/chapter-random.test.ts` 和 `scripts/implementation-ui.js`。重点验证门控、三阶段持久化、章节匹配、随机复现、一次领奖、真实受击与手机布局。针对视效的部分浏览器用例使用隔离存档夹具，不代表正常开局会额外发牌。

## 专属卡池、遗物与重置（2026-10-17）

参考 [Mega Crit 官方角色与构筑介绍](https://www.megacrit.com/press-kits/slay-the-spire-2/) 的独立角色玩法方向，在本项目中实现原创卡组与数值；“重置”规则采用用户指定主题，不将它表述为原作同名机制。

| 角色 | 专属卡牌与构筑 | 起始遗物 |
| --- | --- | --- |
| 蓝色织忆者 | 瞬时调用：0 费 4 伤、消耗；轻量调度：0 费 3 格挡、抽 1、消耗；并发连奏：1 费 3 伤 × 3、抽 1；证据流转：0 费抽 3、消耗 | 记忆丝线：首回合多抽 1；每回合第 3 张牌额外抽 1，每回合一次 |
| 橙色铸序师 | 全力执行：2 费 24 基础伤害；执行蓄势：1 费 4 力量、消耗；终局交付：3 费 42 基础伤害、消耗 | 秩序砧石：每回合第一张至少 2 费的攻击额外 +8 伤害 |
| 绿色观测者 | 状态修复：1 费回复 4 并获得 5 格挡、消耗；持久防线：2 费 16 格挡；稳态反击：1 费 6 伤害并获得 5 格挡 | 重置：每幕一次主动回复 30 生命，需先完成本场两步工程决策 |

- 三套十张起始牌组由 `CHARACTERS.starterDeck` 定义。`CardDef.character` 过滤奖励和商店：专属牌只出现于本角色，共用牌继续按幕解锁。专属牌的新奖励与商店遵循当前章节，已获得的牌允许跨幕使用；每张牌的教材引用与独立试炼的章节要求仍然有效。
- 重置在战斗中使用，不消耗能量；满血时不可使用，不会复活。每幕最多一次，进入新幕恢复额度。未用额度转成一张 **Banked Reset（重置卡）**，牌组中最多储存一张，普通奖励与商店不会随机生成它。
- 重置卡为 1 费，回复 30 生命，跨回合保留；使用后本场消耗，并永久从远征牌组移除。两种重置均使用 `RESET_HEAL`，不随生命上限扩大。没有使用的卡可带到后续战斗。结算与刷新不能重复领取额度或恢复已用卡。它只回复生命，不回退敌人、牌堆、能量、随机数或知识进度。
- 平衡补丁的新生命、最大能量和起始牌组在新局生效；旧档保留已保存的资源和牌组，不按新模板重建。旧档使用新版卡牌、30 点重置与每回合一次丝线规则。检查整套新平衡应重新开局。
- `resetCharges`、`cardsPlayed`、`burstUsed` 为可验证、可保存的可选字段；缺少额度的旧存档不会凭空获得重置。新开一局获得新的起始牌组与遗物；旧遗物身份保留，历史跨角色专属牌在恢复时转换为同类型通用牌，保留实体 UID 和升级状态。三牌抽牌和砧石爆发的计数每回合清零，重置额度不会随战斗重开而恢复。
- 多段攻击逐段结算力量、虚弱、易伤与格挡。零费快攻/抽牌以消耗控制循环；手牌上限仍为 10。升级沿用现有数值规则，完整回复生命的重置卡不改为固定数值治疗。
- `tests/character-kits.test.ts` 覆盖专属池、连击、抽牌遗物、爆发每回合一次、重置门控、过幕储存、一次性移除及存档校验。`scripts/character-kits-ui.js` 验证桌面/手机、按钮、回血、刷新及保留卡消费；其中重置卡 UI 使用隔离存档夹具。
- 当前 **81 项测试**、构建和两组角色浏览器脚本通过；30 个固定种子下，含重置策略的自动玩家错误作答 25 胜、正确应用与迁移 26 胜，三种角色各十个种子均有可通关路线。该结果仅用于流程回归，历史数值记录不是当前胜率。
