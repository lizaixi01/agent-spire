# 十章首领与事件

每章是一幕。每个新首领只有一个主机制，规则、当前进度和下次行动在战斗中公开；三种角色均可通过基础牌应对。数值、封印、反击等均为原创游戏规则，不能理解为教材对真实 Agent 性能的结论。

设计参考《杀戮尖塔2》的路线取舍与首领决策。Mega Crit 在 [2026 年 5 月官方开发通讯](https://www.megacrit.com/news/2026-5-22-neowsletter-issue-22/)中解释，Doormaker 虽有有趣的微观决策，但复杂度超出预期，因此被替换。本项目据此控制每场的主规则数量，并将状态与反制方式直接显示。

| 章 | 首领机制与应对 | 本章事件的实际选择 |
| --- | --- | --- |
| 1 · 入门 | 忘却守卫：每轮技能/能力先于攻击可解除减伤，形成观察与行动的闭环 | 中断的行动日志：接受生命代价换预算，或进入闭环知识试炼 |
| 2 · 上下文 | 窗口吞噬者：每轮超出四张牌后，额外牌会增加首领格挡及本次攻击 | 溢出的上下文档案：支付金币，指定移除一张旧牌，减少常驻负担 |
| 3 · 记忆/RAG | 记忆迷宫：记住打过的牌；重打同名牌每轮可触发一次召回，破盾、易伤并抽牌 | 带来源的检索索引：付费选择一张本章、本角色合法新牌 |
| 4 · 工具 | 协议断路者：技能→攻击的接口契约将重击转为防御，错误顺序需重新准备 | 未声明的工具契约：支付金币升级指定牌 |
| 5 · Coding Agent | 故障构装：连续同名动作减伤并遭反击；改变行动才能恢复 | 可回滚的故障现场：回滚一张升级牌，换取恢复预算 |
| 6 · 交互 | 边界游魂：沙箱准备轮保留最多 16 格挡，执行轮重击 | 隔离执行舱：付生命准备下一战的一次伤害隔离 |
| 7 · 评估 | 无证之王：连续两轮各打出攻击与格挡牌才解除保命封印；漏轮重置 | 固定种子复测台：押注下一战的两步独立决策，按实际正确性结算 |
| 8 · 后训练 | 奖励幻象：可主动领取能量诱饵，但首领回血并永久强化 | 漂亮的代理指标：用永久生命上限换取即时金币 |
| 9 · 持续进化 | 遗忘之核：适应上轮伤害最大的牌，鼓励更换动作并观察新抗性 | 离线经验整合：升级指定副本，并移除另一张同名未升级牌 |
| 10 · 协作 | 回环议会：指挥者、执行者与审核者分工；先破支援可解除减伤和群体护盾 | 独立审核交换站：用两种不同药水换一件未拥有的通用遗物 |

事件均可选择本章试炼或离开。新地图每幕第五层安排事件与商店分支，仍然只允许沿地图连线移动。费用、目标资格、生命风险和下一战条件在点击前显示，资源不足或没有目标时禁用；引擎也会独立拒绝非法请求。

## 保存与获取约定

- `src/boss-mechanics.ts` 管理首领状态与纯规则，`engine.ts` 统一结算；预览和执行共用 `enemyIntent`。攻击牌、药水与侵蚀都经过连续验收的生命下限，无法绕过封印。
- 新机制随战斗保存。存档校验拒绝跨章机制、非法阶段、未知卡牌记忆和伪造保护类型。已有旧版首领保持原规则，避免在战斗中途更换机制；下一场新战斗应用新规则。
- `src/chapter-events.ts` 同时生成界面目标与引擎资格条件。检索只发本章合法新卡；已有旧牌可升级、移除或整合；遗物交换只用通用池。读取预览不消耗随机状态。
- 隔离与复测准备可跨房间保存，进入下一场战斗时转移到战斗状态并清除准备。隔离只抵消一次攻击或反击；复测只有两步均正确时额外结算一次。失败不返还押注。
- 每次事件结束离开事件屏幕；重复调用不能重复领奖、合并或收费。

## 验证入口

`npm test`、`npm run check`、`npm run build`。

- `tests/chapter-bosses.test.ts`：十种反制、动态意图、药水/侵蚀封印、教学门控。
- `tests/chapter-events.test.ts`：十章事件实际结算、费用与目标拒绝、三角色获取矩阵。
- `tests/encounter-save.test.ts`：中途恢复、旧版首领兼容与损坏状态拒绝。
- `tests/expedition.test.ts`：相同公开战斗规则下的九十次策略远征，每步检查存档、角色与章节归属；用于流程回归，不代表人类胜率或教学效果。
- 浏览器脚本 `chapter-encounters-ui.js`、`engineering-feedback-ui.js`：正式构建中的十章事件、首领进度、真实点击、手机三目标选择与解析显示/重载。其余既有浏览器脚本继续覆盖章节、角色、旧存档与正常游玩。
