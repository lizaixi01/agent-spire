# Agent 尖塔 · 游玩说明

这是预构建游玩包，不需要 npm install、Python 或模型 API 密钥。

1. 解压整个 ZIP。
2. 安装 Node.js 22.12+（或 20.19+）。已有兼容 Node.js 时无需重复安装。
3. Windows 双击「启动游戏.cmd」。macOS / Linux 在解压目录运行 `node scripts/serve-game.mjs`，再打开 http://127.0.0.1:4173/。

请通过本地服务器游玩，不要直接双击 dist/index.html。Windows 启动器会在后台运行服务器；重启电脑后停止。macOS / Linux 用 Ctrl+C 停止。

数字键 1—9 出牌，E 结束回合，Esc 关闭面板。点击敌人选定目标，也可拖动攻击牌。工程决策需要完成行动与迁移两步后才解锁本场出牌。

存档只在当前浏览器、当前地址保存；清除站点数据会删除进度。端口不同则存档独立。升级时解压到新目录，继续使用原来的浏览器和地址；无需覆盖旧文件。

没有联网对战或模型调用；安装 Node.js 后游戏可离线运行。字体许可随 dist/pixel/fonts/ 保留。教材原 PDF 未随包分发。模型品牌形象用于角色识别，不代表实际能力排名或官方合作。
